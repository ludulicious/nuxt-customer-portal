## Requirements

- A current Node.js LTS release
- `pnpm`
- PostgreSQL
- Git

## Create a project

Create a new application from the GitHub template:

```bash [Terminal]
npx nuxi init -t github:ludulicious/customer-portal my-customer-portal
cd my-customer-portal
pnpm install
```

The [Customer Portal repository](https://github.com/ludulicious/customer-portal) is also configured as a GitHub template. Select **Use this template**, create your own repository, and then clone the generated project.

## Configure the environment

Copy the example environment file:

```bash [Terminal]
cp .env.example .env
```

Generate a unique Better Auth secret:

```bash [Terminal]
openssl rand -base64 32
```

Set at least these values:

```dotenv [.env]
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/customer_portal
PUBLIC_URL=http://localhost:3051
BETTER_AUTH_URL=http://localhost:3051
BETTER_AUTH_SECRET=<paste-the-generated-secret>
PORTAL_REGISTRATION_MODE=open
```

`DATABASE_URL` must point to an existing PostgreSQL database. `PUBLIC_URL` and `BETTER_AUTH_URL` must match the URL from which the application is served. Keep `BETTER_AUTH_SECRET` private and stable; the pinned product `.env.example` does not yet include this library-owned production requirement.

## Apply the database migrations

Customer Portal keeps one ordered Drizzle migration history for portal core and all enabled feature layers.

```bash [Terminal]
pnpm exec drizzle-kit migrate
```

Review migrations before applying them to an existing or production database.

## Start the application

```bash [Terminal]
pnpm dev
```

The development server listens on <http://localhost:3051> by default.

Create your first account through the registration page. To grant system-administrator access automatically, add the account’s email address to `ADMIN_EMAILS` before signing in.

## Verify the checkout

Run the project checks before making changes:

```bash [Terminal]
pnpm test:features
pnpm lint
pnpm typecheck
pnpm build
```
