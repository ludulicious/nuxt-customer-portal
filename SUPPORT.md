# Customer Portal support

Customer Portal community support currently happens through GitHub issues and pull requests. GitHub Discussions are not enabled, and the project does not promise a response time.

| Need | Where to go |
| --- | --- |
| Installation or implementation question | [Open a question](https://github.com/ludulicious/nuxt-customer-portal/issues/new?template=question.yml) |
| Reproducible product bug | [Report a bug](https://github.com/ludulicious/nuxt-customer-portal/issues/new?template=bug-report.yml) |
| Product enhancement | [Request a feature](https://github.com/ludulicious/nuxt-customer-portal/issues/new?template=feature-request.yml) |
| Reusable business capability | [Propose a layer](https://github.com/ludulicious/nuxt-customer-portal/issues/new?template=module-proposal.yml) |
| Documentation problem | [Report a documentation issue](https://github.com/ludulicious/nuxt-customer-portal/issues/new?template=documentation.yml) |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md); do not open a public issue |

Search the [documentation](https://nuxt-customer-portal.com) and existing issues first. Include a minimal reproduction and the exact Customer Portal commit. Remove customer information and secrets from screenshots, logs, and examples.
