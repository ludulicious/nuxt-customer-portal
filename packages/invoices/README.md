# `@nuxt-customer-portal/invoices`

Standalone sales and received invoicing for Nuxt Customer Portal. Add the optional
`@nuxt-customer-portal/invoice-timesheets` layer to create invoices from approved time.

Draft invoice editing includes line descriptions, quantities, units, prices, VAT, and adding or removing lines, with live totals. Creation and editing share a sortable line list: select a line to expand its fields, reorder using the same drag-preview and automatic edge-scrolling pattern as the media library, or focus the handle and use arrow keys, and use Done to collapse it. Only one line's fields are mounted at a time. Adding a line opens it and focuses its description; invalid collapsed lines reopen on submission. VAT rates display percentage signs. Existing line IDs and linked time entries are retained for edited or reordered lines; removing a line releases its linked time entries. Creation from approved time still prevents removing source-linked lines. Issued, paid, and void invoices cannot be edited. Exact tax amounts are preserved unless quantities, prices, or VAT change. Purchase-backed drafts must retain their agreed total, and financial line changes require tax review again. Failed saves retain the editor and its inputs.

The New invoice action links directly to the creation page. Duplicating or crediting an invoice opens the newly created draft directly in edit mode. Normal detail visits remain read-only until Edit is selected. Optional invoice sources load independently of the manual invoice wizard; a source failure shows a warning without blocking free-form creation. Bootstrap and invoice-number failures show an error with a retry action rather than leaving an empty page.

When free-form invoicing is the only available source, the wizard starts with client selection and uses two steps: client and invoice details. Back navigation does not reopen the skipped source selection. If an optional source is available, source selection remains visible and step counts follow the chosen flow.

Set **Default VAT (%)** under **Invoices → Workspace settings → Invoice configuration**. The percentage is validated between 0% and 100%, with up to two decimal places, and saved for the active workspace. It initializes new invoice lines, including lines added while editing a draft; it does not overwrite existing line rates or imported source tax amounts.

Sales invoice details retain the list return URL, including search, filters, sorting, direction, and page. Returning with the invoice's Back link or browser history restores the loaded page window and scroll position after fetching fresh list data. Position snapshots contain only pagination and scroll metadata and are scoped to the current user, organization, and list URL in session storage. Changing collection controls resets the list to page 1 and the top; browser Back/Forward rehydrates those controls from the URL. Links opened directly still return to the default invoice list, and invoices opened from orders retain their order-list return path.

Invoice email status is refreshed on opening an invoice only when an unresolved delivery is due for a check. Delivered, opened, clicked, bounced, failed, suppressed and complained messages are excluded from automatic checks. Unresolved messages are checked at most every five minutes during the first day, hourly after one day, and daily after a week. Failed lookup attempts observe the same cooldown while preserving the last known status. Concurrent requests claim each attempt in the database before contacting the provider.

Manual refresh can check resolved deliveries for later engagement or complaints, with a one-minute cooldown per message. These events are not updated automatically after delivery; receiving them continuously would require a Resend webhook integration.
