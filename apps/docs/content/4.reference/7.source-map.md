This map connects maintained documentation to the canonical monorepo. During the package-ready milestone the links follow `master`; release documentation should pin the corresponding release tag or commit.

## Workspace and demos

- [`package.json`](https://github.com/ludulicious/nuxt-customer-portal/blob/master/package.json) — private workspace commands and Changesets tooling.
- [`pnpm-workspace.yaml`](https://github.com/ludulicious/nuxt-customer-portal/blob/master/pnpm-workspace.yaml) — application and package membership.
- [`LICENSE`](https://github.com/ludulicious/nuxt-customer-portal/blob/master/LICENSE) — repository-wide MIT terms.
- [`apps/demo-apex/portal.config.ts`](https://github.com/ludulicious/nuxt-customer-portal/blob/master/apps/demo-apex/portal.config.ts) — Apex package selection.

- [`apps/demo-apex/app/app.vue`](https://github.com/ludulicious/nuxt-customer-portal/blob/master/apps/demo-apex/app/app.vue) — Apex host entry point.
- [`apps/demo-brutal/portal.config.ts`](https://github.com/ludulicious/nuxt-customer-portal/blob/master/apps/demo-brutal/portal.config.ts) — Brutal package selection.
