This map connects documentation concepts to the public Customer Portal source revision shown at the bottom of every page. Every link below is immutable: it opens the exact file at commit `96bcf575a70f7943c357fc7dd817c02cadb1dee0`, not a moving branch.

Use it to confirm a behavioral claim, find the right extension point, or choose a production example before proposing a portal-core change.

## Application composition

- [`nuxt.config.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/nuxt.config.ts) — root modules, aliases, runtime configuration, API documentation, and application-level behavior.
- [`drizzle.config.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/drizzle.config.ts) — discovery of portal-core and feature-owned schema files into one migration history.
- [`package.json`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/package.json) — supported scripts and the current dependency baseline.

## Compact reference feature

Use Service Requests when you want the smallest complete business layer:

- [`shared/feature.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/layers/service-requests/shared/feature.ts) — policy, navigation, module menu, and two dashboard widgets.
- [`app/plugins/service-requests-feature.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/layers/service-requests/app/plugins/service-requests-feature.ts) — role-aware widget registration.
- [`server/api/service-requests/index.get.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/layers/service-requests/server/api/service-requests/index.get.ts) — validated, authorized, tenant-scoped list endpoint with OpenAPI metadata.
- [`server/db/schema/service-requests.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/layers/service-requests/server/db/schema/service-requests.ts) — feature-owned PostgreSQL schema and cross-schema references.
- [`test/service-request.test.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/layers/service-requests/test/service-request.test.ts) — locale, translation-reference, validation, policy, and dashboard contract tests.

## Production timesheets and invoices

Use Timesheets when you need a mature layer with multiple modules and context-derived capabilities:

- [`shared/feature.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/layers/timesheets/shared/feature.ts) — Timesheets and Invoices modules, menus, dashboard widgets, and typed actions.
- [`app/plugins/timesheets-feature.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/layers/timesheets/app/plugins/timesheets-feature.ts) — capability loading, filtered contributions, badges, landing routes, and active-organization refresh.
- [`server/api/timesheets/capabilities.get.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/layers/timesheets/server/api/timesheets/capabilities.get.ts) — role, workspace, assignment, linked-client, and pending-work capability calculation.
- [`server/db/schema/timesheets.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/layers/timesheets/server/db/schema/timesheets.ts) — the complete feature-owned schema for entry, approvals, clients, rates, reviews, and invoices.
- [`server/utils/timesheet-repository.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/layers/timesheets/server/utils/timesheet-repository.ts) — tenant-scoped domain operations and multi-stage workflow transitions.
- [`shared/types/timesheet.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/layers/timesheets/shared/types/timesheet.ts) — explicit client-facing DTOs and capability contracts.
- [`shared/invoice-email-template.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/layers/timesheets/shared/invoice-email-template.ts) — invoice email template variables and rendering.
- [`server/utils/invoice-pdf.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/layers/timesheets/server/utils/invoice-pdf.ts) — generated invoice document implementation.
- [`test/timesheets.test.ts`](https://github.com/ludulicious/customer-portal/blob/96bcf575a70f7943c357fc7dd817c02cadb1dee0/layers/timesheets/test/timesheets.test.ts) — locale, validation, migration, invoice, approval, and domain contract tests.
