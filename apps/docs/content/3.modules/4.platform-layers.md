The main application's portal.config.ts explicitly composes the platform modules. They remain separate private pnpm workspaces under packages/; they are not independent npm products.

| Module               | Responsibility                                                                  |
| -------------------- | ------------------------------------------------------------------------------- |
| `core`               | Sessions, tenancy, authorization, database, feature registry and config helpers |
| `ui`                 | Neutral layouts, dashboard, navigation, shared controls and notifications       |
| `authentication`     | Sign-in, signup, verification, recovery and account forms                       |
| `organizations`      | Profile, organization membership and invitations                                |
| `administration`     | System administration and feature-owned admin surfaces                          |
| `clients`            | Client profiles, memberships and client module access                           |
| `saas-configuration` | Onboarding, portal settings, branding, appearance and legal content             |

Repository operations in scripts/portal.mjs resolve migration providers and perform diagnostics, provider/admin setup and Harvest import. The removed kit and preset are replaced by repository scripts and explicit application composition. See [architecture](/architecture/overview) and [database migrations](/architecture/database-migrations).
