Run commands from the repository root with the pinned pnpm version.

```sh
pnpm test:modules
pnpm test:tooling
pnpm test:demo
pnpm test:docs
pnpm verify:saas-boundary
pnpm typecheck
pnpm build
pnpm format
pnpm format:check
```

Module tests cover authorization, schemas, workflows and migration contracts. Tooling tests cover manifest ordering and operational imports. Tests requiring a real database use explicit disposable database environment variables; consult the owning test before enabling them.

## Browser verification

Set E2E_DATABASE_URL to a disposable PostgreSQL database whose name ends in _e2e. The database role must be able to create that database and its _demo companion. Setup applies migrations and prepares a synthetic normal-portal administrator before starting either server. Build the main app once, then run:

```sh
pnpm exec playwright install chromium
pnpm test:e2e
```

The same build runs on localhost:4181 in normal mode and localhost:4182 in demo mode. Desktop/mobile checks cover sign-in, onboarding, dashboard/settings, demo identity switching, module routes and read-only settings. Demo-disabled API endpoints must remain unavailable. Browser failures retain traces and screenshots under test-results/portal.

Use the integrated demo database/API tests for shared CRUD, permissions and daily reset behavior. DATABASE_URL must name a disposable migrated database ending in _demo. Never enable demo mode or forced resets against real data.

Documentation browser checks run separately with pnpm test:e2e:docs. Verify changed UI at desktop/mobile sizes and report only checks actually run.
