# Security policy

Do not report a suspected vulnerability through a public issue, pull request, discussion, or documentation feedback form.

- For Customer Portal product vulnerabilities—including authentication, authorization, tenant isolation, organization data, timesheets, invoices, and feature APIs—use private vulnerability reporting from the [Customer Portal Security tab](https://github.com/ludulicious/customer-portal/security) when available.
- For vulnerabilities specific to the documentation site or its deployment, use private vulnerability reporting from the documentation repository's Security tab when available.

If private vulnerability reporting is unavailable, contact the repository owner through GitHub without including exploit details in a public message, then agree on a private channel.

Include the affected commit, impact, prerequisites, reproduction steps, and a suggested mitigation if known. Use synthetic accounts and records. Do not test against organizations, systems, or data you do not own or have explicit permission to assess.

The project does not currently publish versioned security-support windows. Pin deployed commits and review the [compatibility and release documentation](https://portalnuxt.com/reference/compatibility-and-releases) before upgrading.
